# AI训练师小省个人网站

这是一个静态个人网站，可以直接打开 `index.html` 预览，也可以把整个文件夹部署到 GitHub Pages、Vercel、Netlify 或 Cloudflare Pages。

## 文件

- `index.html`：网站结构和所有展示内容
- `styles.css`：视觉风格、响应式布局、动画
- `script.js`：首屏交换界面、滚动显现、鼠标光效
- `favicon.svg`：网站图标

## 修改位置

- 邮箱：在 `index.html` 中搜索 `hello@example.com`
- 项目卡片：在 `index.html` 中搜索 `project-card`
- 工具和书单：在 `index.html` 中搜索 `tool-cloud` 和 `resource-grid`
- 主视觉文案：在 `index.html` 中搜索 `训练 AI，也训练自己`

## 部署

把 `xiaosheng-site` 文件夹里的文件上传到任意静态网站托管服务即可。
